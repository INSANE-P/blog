# 노션 동기화 상세 설계

[ADR-0022](adr/0022-notion-as-source-of-truth.md)·[ADR-0023](adr/0023-images-on-r2.md)의 구현 설계.
실물로 검증한 사실을 반영해 개정했다(2026-09-04).

## 0. 검증으로 확인한 전제

구현 전에 실제 API로 확인한 것들이다. 설계가 여기에 의존한다.

| 확인 항목 | 결과 |
| --- | --- |
| 노션 마크다운 API | `GET /v1/pages/:id/markdown` **동작함** |
| 필요한 API 버전 | **`2025-09-03`** — `2022-06-28`에는 이 엔드포인트가 없다 |
| 이미지 URL | `X-Amz-Expires=3600` — **1시간 뒤 만료**. R2 이관이 필수임이 확인됨 |
| 표 출력 | 마크다운 표가 아니라 **`<table>` HTML**로 나온다 |
| 줄바꿈 | 문단 내 줄바꿈이 **`<br>` 태그**로 나온다 |
| 코드 블록 | 정상(` ``` ` 펜스). 단 노션에서 언어를 지정해야 언어가 맞게 나온다 |
| R2 업로드·공개읽기·삭제 | 셋 다 성공 |

## 1. 콘텐츠 모델

글의 종류를 나누지 않는다. `기록`/`이야기` 구분과 `핀`은 두지 않는다 — 쓸 때마다 분류를 결정하는 마찰을 없애고, 글이 적을 때 목록이 갈라져 빈약해 보이는 것을 피한다.

```
Post {
  slug        URL
  title       제목
  summary     목록·검색·OG용 한 줄
  date        발행일
  tags        분류
  cover       목록 썸네일 (항상 있음)
  body        마크다운
}
```

## 2. 노션 데이터베이스 속성

**이름을 바꾸면 동기화가 깨지므로 코드에 상수로 고정한다.**

| 노션 속성 | 타입 | → `posts` 컬럼 | 비고 |
| --- | --- | --- | --- |
| `제목` | 제목(title) | `title` | |
| `슬러그` | 텍스트 | `slug` | **직접 입력.** 제목이 바뀌어도 URL 고정 |
| `발행` | 체크박스 | `published_at` | 켜면 공개 |
| `날짜` | 날짜 | `entry_date` | |
| `태그` | 다중 선택 | `tags`/`post_tags` | 이름 기준 upsert |
| `요약` | 텍스트 | `excerpt` | 비우면 본문 앞부분에서 생성 |
| (페이지 커버) | — | `cover_image` | 속성이 아니라 **페이지 커버**에서 읽는다 |
| (페이지 ID) | — | `notion_page_id` | **안정 키.** upsert 기준 |

**삭제할 속성**: `종류`, `핀`

### 커버 이미지

목록에 썸네일을 **항상** 노출하므로 커버가 비면 안 된다. 세 단계로 확보한다.

1. **노션 페이지 커버** — 목록에 보일 이미지를 의도해서 고를 수 있고, 노션에서 빠뜨렸는지 한눈에 보인다
2. 없으면 **본문 첫 이미지** (기존 `coverOf()` 로직)
3. 둘 다 없으면 **제목 활자로 커버를 자동 생성** — 매번 이미지를 준비하지 않아도 목록이 무너지지 않는다

페이지 커버도 서명 URL이라 만료된다. 본문 이미지와 **같은 파이프라인으로 R2에 옮긴다**.

## 3. 동기화 파이프라인

```
1) 목록 조회    노션 DB 쿼리 → 페이지 속성 + 페이지 커버
2) 본문 조회    GET /v1/pages/{id}/markdown  (Notion-Version: 2025-09-03)
3) HTML 정리    <table> → 마크다운 표,  <br> → 줄바꿈
4) 이미지 처리  커버 + 본문 이미지 → 다운로드 → 축소·WebP → R2 → URL 치환
5) 반영        posts upsert (notion_page_id 기준) + 태그 동기화
6) 캐시 무효화  revalidatePath
```

### 단계별 규칙

**2) 본문 조회** — 노션 공식 마크다운 API를 쓴다. 변환기를 직접 만들지 않는다. DB 쿼리는 `2022-06-28`, 마크다운은 `2025-09-03`으로 **버전을 나눠 호출한다**.

**3) HTML 정리** — 노션이 표와 줄바꿈을 HTML로 내보낸다. 렌더러에 HTML 실행을 허용하는 대신([ADR-0012](adr/0012-read-data-flow.md)의 XSS 안전 전제를 지키기 위해) **동기화 시점에 마크다운으로 되돌린다**. 대상은 `<table>`과 `<br>` 둘뿐이라 범위가 좁다.

**4) 이미지 처리** — [ADR-0023](adr/0023-images-on-r2.md)
- 긴 변 1600px 축소 + WebP 변환 (gif·svg는 원본 유지)
- **R2 키는 내용 해시** → 재동기화해도 다시 올리지 않는다(멱등)
- 커버와 본문 이미지를 같은 방식으로 처리한다

**5) 반영** — `notion_page_id`로 upsert.
- 발행 체크가 꺼졌거나 페이지가 사라지면 → **비공개 처리**(삭제하지 않는다). 리액션·댓글이 붙어 있기 때문
- 슬러그가 비면 건너뛰고 경고를 남긴다

### 트리거

| | 방식 | 용도 |
| --- | --- | --- |
| 주 | `POST /api/sync` (토큰 보호) | 글 쓰고 바로 반영 |
| 보조 | Vercel cron 하루 1회 | 놓친 변경 정리 |

Vercel Hobby는 하루보다 잦은 cron을 허용하지 않는다. 함수 실행 시간은 최대 300초라 이미지 처리에 충분하다(확인함).

## 4. 실패 처리

- **한 글이 실패해도 전체를 멈추지 않는다.** 글 단위 성공/실패를 응답에 요약한다
- 이미지 한 장이 실패하면 그 이미지만 원본 URL로 두고 진행한다(만료되므로 로그에 남긴다)
- 동기화는 **멱등**하다

## 5. 화면 구조

| 경로 | 내용 |
| --- | --- |
| `/` | 짧은 소개 + 최근 6편 + 전체 보기 |
| `/posts` | 전체 목록 (연도별 그룹) |
| `/posts/[slug]` | 글 + 진행률 + 목차(h2 4개 이상일 때) + 다음 글 + 불 지피기 + 댓글 |
| `/about` | 소개 + 포폴·GitHub로 나가는 문 |

**없애는 경로**: `/journal`(글 흐름 통합), `/resume`(`resume.chanbin.dev`와 중복), `/admin`·`/login`(노션이 대체)

**태그 페이지는 보류한다.** 글이 적을 때는 태그마다 1~2편이라 얇은 페이지만 늘어난다. 글에 표시만 하고 20편 넘으면 만든다.

## 6. 타이포그래피

근거 등급을 함께 적는다(★ 표준·논문 / △ 관행).

| 항목 | 값 | 근거 |
| --- | --- | --- |
| 줄 길이 | **40자 이하**(약 34rem) | ★ WCAG 1.4.8 — 한중일은 40자 이하 명시 |
| 행간 | **1.8** | ★ WCAG 1.5 이상 + 한글은 베이스라인이 낮아 더 넓게 |
| `word-break: keep-all` | 적용 | ★ 한글 필수. 포폴에 이미 적용돼 있다 |
| 정렬 | 왼끝맞춤 | ★ justify는 한글 어간을 파괴한다 |
| 본문 크기 | 18px (모바일 17px) | △ 관행 |
| 폰트 | Pretendard 하나 | △ 관행. 제목만 Montserrat |

영문 연구(Dyson & Haselgrove 2001, 55자)를 그대로 쓰지 않는다 — 한글은 글자당 정보 밀도가 높아 같은 자수가 훨씬 길다.

## 8. 작업 순서

1. 노션 속성 정리(`종류`·`핀` 삭제), 테스트 글에 페이지 커버 지정
2. 동기화 라우트: 목록 → 본문 → HTML 정리 → upsert (**이미지 없이 먼저 관통**)
3. R2 업로더 + 이미지 파이프라인(커버 포함)
4. 캐시 무효화
5. 디자인 개편 (별도 ADR)
6. 에디터·저널·브랜드 제거
7. R2 커스텀 도메인 연결 (DNS 이전 필요)

2번까지 하면 노션 글이 사이트에 뜬다. 디자인은 데이터가 흐른 뒤에 손댄다.
