# ADR-0041: 소개 페이지 마지막은 방명록

- 상태: 채택
- 날짜: 2026-09-05
- 관련: ADR-0021(giscus 댓글), ADR-0028(커스텀 테마 CSS), ADR-0038(소개 페이지), ADR-0040(iframe 바닥 색)

## 배경

소개 페이지 마지막에 `writing` 절이 있었다. "이 블로그에 무엇을 쓰는지" 한 문단.
읽어 보니 읽으러 온 사람이 궁금해하는 것이 아니라 쓰는 사람의 다짐에 가까웠고,
무엇을 쓰는지는 글 목록을 보면 안다.

## 결정

그 자리에 방명록을 둔다. 소개는 한 사람에 대해 읽는 자리라, 다 읽고 나면 한마디 남기고
싶어지는 곳이 마지막에 있는 편이 자연스럽다.

저장은 글의 댓글과 같은 giscus 다. 백엔드를 새로 만들 이유가 없다.

- **`mapping="specific"` 으로 "방명록" 이라는 한 개의 토론에 모은다.** 경로로 묶으면
  나중에 소개 페이지 주소가 바뀔 때 남긴 글이 통째로 흩어진다.
- 분류는 기존 `댓글` 카테고리를 그대로 쓴다. 새 카테고리를 파면 GitHub 쪽 설정이 하나 늘고,
  얻는 것은 목록에서의 구분뿐이다.

## 겉모습은 댓글과 일부러 다르게

글 아래의 댓글은 방금 읽은 것에 대한 **대답**이라 말풍선이 맞다(ADR-0037).
방명록은 지나간 사람이 남기고 간 **쪽지**에 가깝다.
같은 위젯이라도 하는 일이 다르면 다르게 보여야 온 사람이 무엇을 하는 자리인지 안다.

그래서 테마 CSS 를 따로 뒀다(`giscus-guestbook-*.css`).

- **쪽지 카드로 깔린다.** `grid-template-columns: repeat(auto-fit, minmax(280px, 1fr))`.
  `auto-fit` 이라 글이 하나뿐이면 빈 칸이 접혀 카드가 폭을 다 쓴다 —
  `auto-fill` 로 두면 혼자 남은 쪽지가 왼쪽 반만 차지해 어색하다.
  `align-items: start` 가 없으면 짧은 쪽지가 옆의 긴 쪽지 높이까지 늘어난다.
- **이름 아래로 번개가 지나간다.** 이 사이트에서 번개 밑줄은 "지나간 자국"을 뜻한다(ADR-0030).
  방명록에 이름을 남긴다는 것이 정확히 그 뜻이다.
- **반응·답글 수·소유자 표를 지운다.** 방명록은 주고받는 자리가 아니다.
- **남기는 칸은 점선으로 두른다.** 쪽지들이 실선 카드이므로 점선 하나로
  "이건 아직 비어 있다"가 형태로 구분된다. 초점이 오면 실선 악센트로 바뀐다.

클래스 이름은 추측하지 않고 실제 위젯의 DOM 에서 뽑았다.

## 번개 밑줄이 잘리던 것

giscus 는 이름 span 에 `overflow: hidden` 을 걸어 둔다. 밑줄을 상자 밖(`bottom: -6px`)에
그리면 통째로 잘려 나간다 — 소개 페이지 명함에서 똑같이 당했던 함정이다.

우리 쪽 `overflow: visible` 이 이기지 못했다. 우선순위는 우리가 높은데도 그랬고,
읽을 수 있는 스타일시트 어디에서도 이기는 규칙을 찾지 못했다(iframe 안에서 계산값을 떠 봤다).

원인을 더 파는 대신 **잘릴 수 없는 자리**로 옮겼다. 밑줄을 상자 밖이 아니라 `padding` 안쪽에
그린다. padding 은 넘침 자르기의 안쪽이라 overflow 가 무엇이든 잘리지 않는다.
늘어난 높이는 같은 크기의 음수 margin 으로 되돌려 다른 줄이 밀리지 않게 했다.

## 테마 판단은 한 곳으로

댓글과 방명록이 같은 판단(지금 다크인가, 커스텀 CSS 를 쓸 수 있는가)을 해야 해서
`src/lib/giscus.ts` 의 `useGiscusTheme(prefix)` 로 뺐다. 파일 이름 앞부분만 다르게 넘긴다.

## 대가

- 소개 페이지에 iframe 이 하나 늘어난다. `loading="lazy"` 라 화면에 들어와야 뜬다.
- 커스텀 모양은 https 에서만 보인다. 개발 중(http)에는 giscus 내장 테마로 물러난다 —
  iframe 안에서 mixed-content 로 막히기 때문이고, 이건 고칠 수 있는 것이 아니다(ADR-0040).
- 남기려면 GitHub 계정이 필요하다. 개인 블로그의 방명록으로는 받아들일 만하다.
