# ADR-0052: 저장소 이름을 blog 로

- 상태: 채택
- 날짜: 2026-09-05
- 관련: ADR-0024(정체성 재정립), ADR-0021(giscus)

## 배경

저장소 이름이 `frost-log` 였다. 눈과 서리를 세계관으로 쓰던 시절에 지은 이름인데,
ADR-0024 에서 그 세계관을 걷어냈고 사이트도 `chanbin.dev` 로 옮겼다.
이름만 옛 자리에 남아 있었다.

이름은 밖에서 보는 사람에게 먼저 닿는다. 저장소 목록에서 `frost-log` 를 보고
그것이 이 블로그라는 것을 알아볼 사람은 나뿐이다.

## 결정

**`blog` 로 바꾼다.**

멋있는 이름을 다시 짓지 않는다. 이 저장소가 하는 일은 하나이고,
그 하나를 그대로 부르는 것이 가장 짧게 설명하는 방법이다.
간판은 README 가 세우면 된다 - 이름까지 간판일 필요는 없다.

## giscus 가 끊기지 않는 이유

댓글과 방명록은 이 저장소의 Discussions 에 쌓여 있다. 이름을 바꾸면 지워질까 봐 확인했다.

giscus 는 `repo` 문자열과 `repoId` 를 함께 받는다. **매핑을 잡는 쪽은 `repoId`**(`R_kgDOS4XX0g`)이고,
이 값은 저장소를 만들 때 정해져 이름을 바꿔도 움직이지 않는다.
`repo` 문자열만 새 이름으로 고치면 지금까지 달린 글이 그대로 붙어 있다.

GitHub 이 옛 이름에서 새 이름으로 돌려보내 주기 때문에, 고치기 전 잠깐도 깨지지 않는다.
그래도 배포 후에 댓글 하나가 실제로 보이는지는 눈으로 봤다.

## 곁들여 고친 것

`NEXT_PUBLIC_SITE_URL` 의 기본값이 `frost-log.vercel.app` 이었다.
환경변수를 빠뜨렸을 때 canonical 과 OG 가 통째로 그 주소를 가리킨다는 뜻이라,
이제 실제 도메인인 `chanbin.dev` 로 둔다. 틀렸을 때 덜 아픈 쪽이 기본값이어야 한다.

## 건드리지 않은 것

옛 ADR 본문의 `frost` 는 그대로 둔다.
ADR 은 그때 그렇게 정했다는 기록이고, 지금 이름으로 덧칠하면
**무엇을 바꿨는지가 사라진다.** 기록을 고치면 그건 기록이 아니다.
