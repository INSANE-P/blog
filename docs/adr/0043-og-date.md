# ADR-0043: 공유 카드에 날짜를 넣는다

- 상태: 채택
- 날짜: 2026-09-05
- 관련: ADR-0028(공유 이미지)

## 배경

글별 OG 카드에 제목과 워드마크만 있고 **언제 쓴 글인지가 없었다**.
타임라인에서 카드만 보고 넘어가는 사람에게는 그 글이 어제 것인지 재작년 것인지가
제목만큼 중요하다.

아래 줄을 양끝 정렬로 바꿔 왼쪽에 워드마크, 오른쪽에 날짜를 둔다.

제목 위(`eyebrow`)에 얹어 보려다 뒀다. 위쪽은 제목이 화면을 다 쓰라고 비워 둔 자리이고
(ADR-0028), 날짜는 먼저 읽을 것이 아니다. 색도 악센트가 아니라 흐린 회색이다 —
악센트로 두면 제목보다 날짜가 먼저 눈에 든다.

사이트 기본 카드에는 날짜가 없으므로 `meta` 를 넘기지 않으면 아래 줄은 예전 그대로다.
