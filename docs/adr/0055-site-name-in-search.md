# ADR-0055: 사이트 이름은 검색 결과에서 일한다

- 상태: 채택
- 날짜: 2026-09-06
- 관련: ADR-0024(이름을 사람 이름으로), ADR-0044(검색 노출)

## 배경

구글에서 `chanbin.dev` 를 찾으면 이렇게 나왔다.

```
박찬빈
Park Chanbin. 도전하고, 그 과정을 기록합니다. new. all posts · 노션으로 옮긴 첫 글.
노션을 정본으로 삼고 이미지는 R2에 굽는 구조를 시험한다.
```

**"블로그"라는 말이 한 번도 나오지 않는다.** 이걸 보고 누를 이유가 없다.
이미 나를 아는 사람은 알아보겠지만, 검색 결과는 나를 모르는 사람이 보는 화면이다.

두 군데가 어긋나 있었다.

**제목이 `박찬빈` 하나였다.** 검색 결과에서 가장 먼저, 가장 크게 읽히는 줄인데
여기가 무엇을 하는 곳인지 말하지 않았다.

**설명을 구글이 쓰지 않았다.** 우리가 넣어 둔 한 줄("도전하고, 그 과정을 기록합니다.
박찬빈의 개인 블로그.") 대신 화면 글자를 직접 주웠다 - 히어로 문구, 섹션 라벨(`new`,
`all posts`), 그리고 첫 글의 요약 순서다. 그래서 UI 라벨이 문장 사이에 끼고,
마지막이 기술 이야기로 끝났다.

## 결정

**사이트 이름과 사람 이름을 나눈다.**

```ts
name: "개발자 찬빈",              // 사이트가 스스로를 부르는 이름
title: "개발자 찬빈의 블로그",     // 홈의 제목
author: { name: "박찬빈" },       // 글쓴이. 구조화 데이터의 Person 과 피드가 쓴다
```

둘은 하는 일이 다르다. 사이트 이름은 **모르는 사람에게 여기가 무엇인지 말하는 말**이고,
글쓴이 이름은 **누가 썼는지를 기계가 읽는 값**이다. 하나로 쓰면 둘 중 하나가 반드시 어색해진다.

홈만 `title` 을 쓴다. 글 화면은 `글 제목 · 개발자 찬빈` 이면 충분하다 -
그 자리에서는 이미 글이라는 것이 분명하고, 제목마다 "블로그"를 붙이면
검색 결과에서 잘려 나가는 쪽이 정작 글 제목이 된다.

**설명이 무엇을 하는 곳인지부터 말한다.** 좋은 문장을 앞에 두는 것보다,
모르는 사람이 첫 다섯 글자에서 판단할 수 있게 하는 것이 먼저다.

## "개발 블로그"라고 좁히지 않는다

여기는 개발만 쓰는 자리가 아니다. 동아리를 운영한 이야기도, 축제에 부스를 낸 이야기도 쓴다.
제목에 "개발 블로그"를 박으면 그런 글을 쓸 때마다 제목과 어긋난다.

`개발자 찬빈` 은 다르다. **개발자는 나를 설명하는 말이고, 블로그의 주제를 좁히는 말이 아니다.**

## 참고한 것

`jeong-min.com` 은 `<title>`·`og:title`·`description` 이 전부 `개발자 단민` 이다.
이름 짓는 방식은 이걸 따랐다.

설명까지 같게 두는 것은 따르지 않았다. 설명 칸이 제목의 복사본이면 구글에게는 빈 칸과 같고,
그러면 지금 우리가 겪은 일 - 화면 글자를 대신 주워 가는 일 - 이 그대로 일어난다.

## 곁들여 고친 것 — 공유 이미지의 줄바꿈

홈의 공유 이미지가 이렇게 끊겨 있었다.

```
도전하고, 그 과정을 기록합니
다
```

넘겨준 문자열에는 `도전하고,\n그 과정을 기록합니다` 라고 끊는 자리가 있었는데,
`ImageResponse` 는 기본 `white-space` 로 그리므로 그 `\n` 이 그냥 공백이 됐다.
그래서 한 줄로 이어졌고, 폭이 차는 자리에서 잘렸다.

`white-space` 를 바꾸는 대신 **줄을 우리가 나눠 각각 그린다.**
어느 렌더러가 그 속성을 어떻게 해석하는지에 기대지 않는 편이 확실하다.
끊는 자리를 주지 않은 제목(글 제목)은 예전처럼 알아서 접힌다.

글자 크기를 정하는 기준도 **가장 긴 줄**로 바꿨다. 전체 길이로 재면
두 줄로 나눠 놓고도 한 줄짜리처럼 작아진다.

공유 이미지 아래 문구도 사이트 이름을 쓰게 했다. 카드 하나만 봐도 여기가 무엇인지 읽힌다.

## 남는 것

**설명을 넣었다고 구글이 반드시 쓰는 것은 아니다.** 검색어에 따라 페이지 본문을
그대로 쓰는 쪽을 고르기도 한다. 우리가 할 수 있는 것은 "쓸 만한 한 줄을 두는 것"까지다.

다시 색인되기까지 며칠 걸린다. 제목이 바뀐 것을 확인하려면 그만큼 기다려야 한다.
