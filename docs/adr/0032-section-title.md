# ADR-0032: 절 제목은 포트폴리오와 같은 아웃라인 활자

- 상태: 채택
- 날짜: 2026-09-05
- 관련: ADR-0024(시각 정체성), ADR-0026(목록·헤더), ADR-0029(표지와 내용의 언어)

## 결정

### 포트폴리오의 `SectionTitle` 을 그대로 가져온다

포트폴리오의 `Projects`·`Skills` 는 속을 비운 대문자 활자다(`stroke-text` + Montserrat).
같은 사람이 만든 두 사이트가 같은 방식으로 절을 열면, 둘을 오가는 사람이 그것을 알아본다.

크기만 두 단계 낮췄다(포폴 최대 104px → 여기 56px). 포폴에서는 절 제목이 화면의 주인공이지만
여기서는 글이 주인공이다. 72px 로 두고 렌더해 보니 히어로(76px)와 목소리가 거의 같아져
위계가 무너졌다.

획은 1px 이다. 2px 로 굵히면 또렷해지지만 포트폴리오의 얇고 단단한 결이 사라진다.
30px 아래에서는 획이 실처럼 가늘어지므로 clamp 하한을 36px 로 둔다.

### 절 위에 구분선을 긋지 않는다

이만한 활자가 놓이면 그 자체가 절의 시작을 말한다. 선을 더하면 같은 말을 두 번 하는 셈이다.
네 조합(선 있음/없음 × 두 크기)을 렌더해 비교했고, 선이 있는 쪽은 선이 하는 일이 없었다.
사이는 여백으로 벌린다(히어로 아래 96px).

### 글 상세는 예외다

`keep reading`·`comments` 는 26px 그대로 둔다. 홈과 목록은 훑는 화면이라 큰 활자가 이정표가
되지만, 글 상세는 읽는 화면이라 본문 한가운데 56px 짜리 활자가 끼면 읽기가 끊긴다.
같은 시스템 안에서도 화면이 하는 일이 다르면 크기는 달라야 한다.

### 목록 페이지 제목은 `posts`

`all posts` 로 두었더니 브라우저 탭이 `All posts · 박찬빈` 이 되어 어색했다.
홈의 링크는 "전부 보러 가기"라는 뜻이라 `all posts` 가 맞지만, 도착한 페이지의 이름은
`posts` 다. 탭도 `Posts · 박찬빈` 으로 자연스러워진다.

## 결과

- `SectionTitle` 컴포넌트 신설. `as` 로 h1/h2 를 고른다 — 같은 모양이어도 문서 구조는 달라야 한다
- 홈의 `new`, 목록의 `posts` 가 이 제목을 쓴다. 홈의 구분선 제거
