# ADR-0031: 파비콘은 번개와 점

- 상태: 채택
- 날짜: 2026-09-05
- 관련: ADR-0024(시각 정체성), ADR-0028(옛 정체성 정리), ADR-0030(번개 밑줄)

## 배경

ADR-0028에서 공룡 파비콘을 걷어내고 `C` 글자와 점으로 바꿨다. 그런데 실제 크기로 보지 않고
만들었고, 16px 에서 `C` 가 뭉개지며 점이 획과 겹쳐 깨진 그림처럼 보였다.
정체성도 담기지 않았다 — `C` 는 이름의 첫 글자일 뿐 이 사이트가 쓰는 형태가 아니었다.

## 결정

### 번개 하나와 점 하나

둘 다 이 사이트가 **이미 쓰고 있는** 형태다.

- **번개** — 링크에 마우스를 올렸을 때 지나가는 밑줄(ADR-0030). 이 사이트의 유일한 인터랙션 장치다
- **점** — 워드마크 `CHANBIN.` 의 마침표. 헤더·푸터·히어로에 모두 있다

배색도 워드마크와 같다. 흰 글자에 악센트 마침표 → 흰 번개에 악센트 점.
새로 만든 것이 하나도 없다는 점이 중요하다. 파비콘은 정체성을 **요약**하는 자리지
정체성을 **추가**하는 자리가 아니다.

### 16px 에서 골랐다

여섯 가지를 실제 크기(16·20·32·64·110px)로 렌더하고, 다른 탭 사이에 끼워 놓고 비교했다.

| 후보 | 결과 |
| --- | --- |
| `C` 글자 + 점 | 16px 에서 뭉개지고 점이 획과 겹친다 |
| 번개 — 흰색만 | 가장 또렷하지만 브랜드 색이 없다 |
| 번개 — 아래 끝만 악센트 | 16px 에서 색 경계가 사라진다 |
| 번개가 뚫고 지나간 자리(선 추가) | 작아지면 선이 잡음이 된다 |
| 악센트 번개 + 흰 점 | 흰 점이 번개와 싸워 따로 노는 물체로 보인다 |
| **흰 번개 + 악센트 점** | **채택** |

점의 크기는 반지름 8(64 기준)이다. 그보다 작으면 16px 에서 사라지고, 크면 번개를 민다.
번개를 왼쪽으로 밀어 대각선으로 배치했다 — 가운데 모으면 16px 에서 하나의 얼룩이 된다.

### 곡선을 쓰지 않는다

워드마크가 기하학적 산세리프(Montserrat)라 곡선을 섞으면 결이 어긋난다.
직선과 각으로만 그린다. 각이 굵어 작아져도 형태가 남는다는 실용적인 이유도 있다.

### 테마를 따라가지 않는다

악센트는 다크 값(`#5fcdee`)으로 고정한다. 검은 바탕 위에 놓이는 색이라 라이트 값은 탁하다.
브라우저 탭은 우리 화면 밖이고, 탭 막대는 라이트든 다크든 검은 사각형이 잘 보인다.

## 결과

- `public/favicon.svg` 교체. 새 자산이나 색을 추가하지 않았다

## 남는 문제

- 애플 터치 아이콘(홈 화면 추가)은 두지 않았다. 필요해지면 같은 그림을 180px PNG 로 뽑는다
