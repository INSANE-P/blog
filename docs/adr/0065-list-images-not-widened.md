# ADR-0065: 목록 안 그림은 넓히지 않는다

- 상태: 채택
- 날짜: 2026-10-20
- 관련: ADR-0046(그림 크기)

## 맥락

가로로 긴 그림은 본문(656px)보다 넓게, 최대 832px 까지 양쪽으로 똑같이 넓힌다(ADR-0046). 그런데 따라 하기 번호 목록 안의 그림은 오른쪽으로만 튀어나갔다.

| 화면 | 왼쪽 | 오른쪽 |
| --- | --- | --- |
| 데스크톱 | 본문 밖 74px | 본문 밖 102px |
| 휴대폰(390px) | 본문 안 10px | 본문 밖 18px |

넓힐 때 기준을 `margin-left: 50%` 와 `translateX(-50%)` 로 "부모 칸의 가운데"에 둔다. 목록 안에서는 부모가 들여쓴 목록 칸이라 기준이 오른쪽으로 밀렸다. 연재 2, 3, 4편의 따라 하기 그림 열 장이 해당했다. ADR-0063 로 그림이 목록 항목 안에 제대로 들어가면서 더 잘 보이게 됐다.

## 결정

목록 안의 넓은 그림은 넓히지 않고 목록 칸 폭에 맞춘다.

## 이유

- 따라 하기 그림은 그 단계 글과 같은 줄에서 시작해야 어느 단계의 그림인지 읽힌다. 본문 밖으로 넓히면 단계 번호와 그림의 관계가 흐려진다
- 목록 칸은 본문보다 28px 좁을 뿐이라 그림이 작아지는 손해가 적다

## 대안

- **목록 들여쓰기만큼 기준을 왼쪽으로 옮겨 본문 기준으로 넓히기**: 들여쓰기가 중첩마다 달라 값을 하나로 정할 수 없고, 넓혀도 단계와 그림이 어긋나는 문제는 남는다

## 결과

- 목록 안 그림의 오른쪽 끝이 본문 오른쪽 끝과 맞는다(데스크톱, 휴대폰 모두 확인)
- 목록 밖 그림은 그대로 넓게 보인다
