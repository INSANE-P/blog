# ADR-0028: 옛 정체성 잔재 정리와 모바일·댓글 화면

- 상태: 채택
- 날짜: 2026-09-05
- 관련: ADR-0021(giscus 댓글), ADR-0024(시각 정체성), ADR-0026(목록·헤더), ADR-0027(본문 읽기)

## 배경

ADR-0024에서 불꽃·서리·공룡을 걷어냈는데, **화면에서만 걷어내고 코드에는 그대로 남아 있었다.**
그 결과 눈에 보이는 고장이 생겼다.

- `StokeButton` 의 불꽃이 `--flame-*` 토큰을 참조하는데 그 토큰을 지워, 정의되지 않은 색으로 그려지고 있었다
- `animations.css` 487줄 중 `flame-logo`·`ice-overlay`·`frost-rise`·`dino-pop`·`type-caret` 은
  tsx 어디에서도 쓰이지 않았다
- giscus 커스텀 테마가 옛 frost 색(`#f4f9fc`·`#1f3947`)이라 댓글창만 다른 사이트처럼 보였다
- Gmarket Sans 웹폰트 세 벌(1.8MB)이 로더에만 남아, 쓰이지도 않으면서 배포에 들어갔다
- 사이트 이름·OG·파비콘이 여전히 "설화"와 공룡이었다

교훈은 하나다 — **화면에서 지운 것은 코드에서도 지워야 한다.** 남겨 두면 언젠가
"왜 이게 이상하지"로 돌아온다.

## 결정

### 1. 글 끝 반응을 스파클로 바꾼다

"불 지피기"는 설화·서리 정체성에 딸린 은유였다. 그 정체성을 걷어내면 은유만 남고 근거가 없다.
다크 모드의 별과 같은 스파클을 쓴다 — 이 사이트 안에서 뜻이 이어지고, 반짝임은 설명 없이
"좋았다"로 읽힌다. 문구도 "좋았어요 / 고마워요"로 바꿨다.

기능 자체는 남긴다. **로그인을 요구하지 않는 것이 이 버튼의 존재 이유다.**
댓글은 GitHub 계정이 있어야 하지만, 글이 좋았다는 말은 그 문턱 없이 남길 수 있어야 한다.
숫자는 누른 사람에게만 보인다 — 0 으로 시작하는 숫자가 먼저 보이면 누르려던 사람도 손을 거둔다.

### 2. 모바일 메뉴는 전체 화면으로

작은 화면에서 드롭다운을 띄우면 목적지가 손가락 하나 크기로 줄어든다.
화면 전체를 쓰면 어디를 눌러도 닿는다(피츠의 법칙). 항목이 둘뿐이라 채울 것이 없다는 점이
오히려 이 방식에 맞는다 — 큰 활자 두 개가 화면의 주인이 된다.

열릴 때 항목이 차례로 올라온다. 한 번에 나타나면 화면이 갈아 끼워진 것처럼 보이는데,
순서가 있으면 "메뉴가 열렸다"로 읽힌다. 전환은 다음 프레임에 켠다 — 같은 프레임에 켜면
애니메이션 없이 끝난 상태로 그려진다.

닫는 길을 셋 둔다(X · Esc · 항목 선택). 전체 화면을 덮는 것은 빠져나갈 길이 분명해야 한다.
경로가 바뀌면 자동으로 닫는다.

### 3. 돌아가기는 아이콘 버튼이 아니라 글줄에 맞춘 텍스트로

40px 짜리 아이콘 버튼이 본문 바로 위에 떠 있으면 어느 선에도 맞지 않아 혼자 얹혀 보인다.
`← 목록으로` 처럼 글자로 두면 아래 태그·제목과 왼쪽 선이 맞는다.
헤더로 올리는 안도 있었지만, 헤더는 사이트 전체가 쓰는 자리라 글 화면에서만 항목이
늘어나면 헤더의 뜻이 화면마다 달라진다.

### 4. 댓글 상자 위에 우리 표식과 한 줄을 둔다

giscus 는 로그인 전에 "Sign in with GitHub" 만 보여 준다. 그것만으로는 왜 로그인해야 하는지가
보이지 않는다. 무엇을 남기면 되는지 먼저 말한다.

옆의 표식은 사람 아이콘이 아니라 **해** 다 — 테마 토글의 라이트 모드와 같은 광선이라
헤더에서 본 것이 여기서 다시 나온다. 기본 아바타는 어느 블로그에나 똑같이 붙어 있어
"여기가 누구의 자리인지"를 말해 주지 않는다. 마스코트를 새로 만들지 않는 것은
유지할 브랜드 자산을 늘리지 않기 위해서다(ADR-0024).

댓글에 달리는 GitHub 아바타는 giscus 가 이미 보여 준다. 원 대신 둥근 사각형으로만 바꿨다 —
이 사이트의 면은 전부 둥근 사각형이라(카드 18px · 코드 14px · 칩 9px) 아바타만 원이면
혼자 다른 문법을 쓴다. 얼굴 자체는 그대로 둔다. 누가 썼는지는 얼굴이 가장 빨리 말해 준다.

### 5. 소셜 공유 이미지와 파비콘도 활자로

OG 카드에서 마스코트를 빼고 제목 하나가 화면을 다 쓰게 했다. 공유 카드는 타임라인에서
손톱만 하게 줄어드는데, 그림과 글자가 자리를 나눠 가지면 둘 다 안 읽힌다.
배경은 검정이다 — 타임라인은 흰 카드가 줄지어 있는 곳이라 검은 카드 하나가 눈에 걸린다
(폰 레스토프 효과). 사이트의 다크 모드와도 같은 화면이 된다.

파비콘은 검은 사각형 위 흰 `C` 와 악센트 점 — 워드마크의 첫 글자와 마침표다.
탭에서는 5mm 남짓으로 줄어드는데 이름 전체를 넣으면 아무것도 안 읽힌다.
포트폴리오가 붓으로 흘려 쓴 `P` 를 쓰는 것과 같은 문법이다(같은 사람, 다른 자리).

### 6. 사이트 이름을 "설화"에서 사람 이름으로

불꽃·서리를 걷어내자 그 이름이 가리키던 것이 화면에 하나도 남지 않았다.
포트폴리오와 같은 사람이라는 사실이 이름에서 바로 읽히는 편이 낫다.

## 결과

- `animations.css` 487줄 → 60줄. 남은 것은 테마 전환 하나뿐이다
- Gmarket Sans 세 벌(1.8MB) 삭제. 제목은 Montserrat + Pretendard 로 간다
- `dino.png`·`dino-hug.png`·`og-dino-data.ts`·`public/covers` 삭제
- giscus 테마 파일 이름을 `giscus-{light,dark}.css` 로 바꾸고 색을 현재 토큰과 맞췄다.
  **이 값은 `tokens.css` 와 같아야 한다** — 여기만 옛 색이 남으면 댓글창만 다른 사이트처럼 보인다

## 남는 문제

- giscus 테마 CSS 의 색은 손으로 맞춘 사본이라 토큰이 바뀌면 같이 고쳐야 한다.
  `pnpm check:contrast` 는 이 파일을 보지 않는다
- 메뉴 항목 라벨("글")은 아직 정하지 않았다
