# ADR-0064: 노션이 이스케이프하지 않는 본문 글자를 막는다

- 상태: 채택
- 날짜: 2026-10-20
- 관련: ADR-0022(노션 정본), ADR-0063(블록 사이 빈 줄)

## 맥락

ADR-0063 을 고치며 실물 아홉 편을 보니, 노션 마크다운 엔드포인트가 이스케이프하는 글자는 물결표(`~`) 하나뿐이었다. 나머지 글자는 본문 그대로 오고, 렌더러는 그중 몇 가지를 문법으로 읽는다. 지금 글에는 해당하는 문장이 없지만, 가짜 문장을 넣어 보니 전부 실제로 깨졌다.

| 본문 | 렌더러가 읽은 것 |
| --- | --- |
| `자세한 건 https://example.com에서 본다` | "에서"까지 링크 주소에 붙는다. GFM 은 주소가 한글에서 끝나는 줄 모른다 |
| `타입은 Array<string> 으로 받는다` | `<string>` 을 태그로 보고 지운다(변환기가 남은 태그 껍데기를 벗긴다) |
| `요금은 $5에서 $10으로 올랐다` | 두 `$` 사이를 수식으로 바꾼다 |
| `1) 첫째 이유는 비용이다` | 번호 목록이 된다 |
| `2026. 10. 20 에 바꿨다` | 목록 안의 목록이 된다 |

## 결정

변환기에서 아래만 손댄다. 코드는 자리표로 빠져 있을 때 처리해서 건드리지 않는다.

- **주소 바로 뒤 한글**: 주소를 꺾쇠로 감싸 끝을 정한다. 링크 문법 안의 주소(`](`, `[` 뒤)는 건드리지 않는다
- **꺾쇠 글자**: 노션 블록 태그는 닫는 짝이 있거나, 스스로 닫거나(`/>`), 속성(`=`)이 붙어서 온다. 셋 다 아닌 꺾쇠는 본문 글자로 보고 이스케이프한다. 모르는 노션 태그를 벗기고 보고하는 동작(ADR-0022)은 그대로다
- **숫자 앞 `$`**: 돈이라 이스케이프한다. 노션 수식(`$x^2$`)은 숫자로 시작하지 않아 그대로 둔다
- **`1)` 로 시작하는 줄**: 노션은 번호 목록을 `1.` 로만 내므로 언제나 본문이다
- **세 자리 넘는 숫자와 점으로 시작하는 줄**: 연도다. 번호가 세 자리인 목록은 없다고 본다

## 대안

- **`$` 를 모두 이스케이프**: 노션 수식이 깨진다
- **모든 `1.` 을 의심**: 진짜 번호 목록과 구별할 수 없다. 노션은 목록이 아닌 줄의 `1.` 도 이스케이프하지 않는다
- **노션에서 글을 쓸 때 조심하기**: 쓰는 사람이 마크다운 규칙을 기억해야 한다. 그러면 노션을 정본으로 쓰는 이유(ADR-0022)가 줄어든다

## 결과

- 지금 발행한 아홉 편의 변환 결과는 한 줄도 바뀌지 않는다(줄 단위로 견줬다)
- `pnpm check:notion` 에 여덟 가지 경우를 더했다. 진짜 번호 목록과 노션 수식이 그대로인지도 본다
- 남은 한계: 세 자리 미만 숫자와 점으로 시작하는 본문 줄(`10. 20 에`)은 여전히 목록이 된다. 진짜 목록과 구별할 수 없다
