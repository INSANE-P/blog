# ADR-0054: 영상 제목은 동기화가 받아 둔다

- 상태: 채택
- 날짜: 2026-09-06
- 관련: ADR-0051(유튜브 임베드), ADR-0044(순수 함수로 만든 피드)

## 배경

노션이 내보내는 유튜브 링크의 텍스트는 언제나 `video` 다.

```
[video](https://www.youtube.com/watch?v=amy704I2PxQ)
```

우리는 그것을 그대로 `aria-label` 과 `iframe title` 에 썼다. 한국어 글 안에서 영어 단어 하나가
튀고, 무엇을 누르는지도 알려주지 않는다. 이 영상의 진짜 제목은
"미야기의 캡틴은 고개 숙이지 않는다"(동수칸TV)다.

## 결정

**동기화가 oEmbed 로 제목과 채널을 받아 마크다운에 박는다.**

```
[미야기의 캡틴은 고개 숙이지 않는다](https://www.youtube.com/watch?v=… "동수칸TV")
```

화면에서 물을 수도 있었다. 그러지 않은 이유는 하나다 -
**렌더 경로에 외부 서비스가 끼면 그 장애가 곧 사이트 장애가 된다.**
이 블로그는 그 원칙 위에 세워져 있다. 노션조차 화면에서 조회하지 않는데
영상 제목 하나를 위해 예외를 만들 이유가 없다.

채널은 링크의 title 자리에 둔다. 마크다운 문법 안이라 원문을 그대로 읽어도 자연스럽고,
우리 화면 밖(RSS·검색 결과·원문 보기)에서도 제목이 제목으로 읽힌다.

**title 이 이미 있으면 다시 묻지 않는다.** 글을 고칠 때마다 같은 것을 물으면
동기화만 느려진다. 이 표시가 곧 "이미 채웠다"는 뜻이다.

**못 받으면 원래 텍스트를 둔다.** 제목 하나 때문에 발행이 막히는 것이 훨씬 큰 손해다.
못 받아도 예전과 같은 모습이 될 뿐이다. 화면은 `video` 같은 기본 텍스트를 알아보고
띠를 아예 달지 않는다 - "video" 한 줄을 띄우느니 그림만 보여주는 편이 낫다.

### import 가 없는 파일

`youtube-titles.ts` 에는 import 가 하나도 없다. `pnpm check:notion` 이 이 파일을
그냥 node 로 불러 검사하는데, node 는 확장자 없는 TS import 를 풀지 못한다.
그래서 "이 주소가 유튜브인가"를 인자로 받는다.

`feed.ts` 와 같은 이유이고, 같은 이유로 설계도 나아졌다.
이 파일은 "링크를 찾아 제목을 박는다"만 알고, 유튜브 주소의 생김새는 부르는 쪽이 안다.

덕분에 대괄호가 든 제목(`[속보] 어쩌고`)이 링크를 깨뜨리지 않는지,
큰따옴표가 든 채널 이름이 title 을 닫아 버리지 않는지를 망 없이 검사할 수 있다.
둘 다 실제로 처음에 틀렸고, 검사가 잡았다.

## 곁들여 고친 것

**썸네일을 `maxresdefault` 로 올렸다.** 쓰고 있던 `hqdefault` 는 480px 라
본문 폭에서 흐렸다. `maxresdefault` 는 1280px 이고 레터박스도 없다.
2010년 즈음 이전 영상에는 없으므로 `hqdefault` 로 물러난다 -
4:3 의 검은 띠는 16:9 칸에 `object-cover` 로 채우면 잘려 나간다.

**재생 파라미터를 붙였다.** `hl=ko`·`cc_lang_pref=ko` 로 플레이어를 한국어로 열고,
`playsinline=1` 로 iOS 에서 전체화면으로 튀지 않게 하고,
`color=white` 로 진행 막대의 빨강을 지운다. 이 화면에 빨강은 어디에도 없다.

`rel=0` 도 넣었다. **관련 영상을 없애지는 못한다** - 2018년부터 같은 채널로 좁힐 뿐이다.
그래도 남의 채널로 끌려가는 것보다는 낫다.

`modestbranding` 은 넣지 않았다. **2023-08-15 에 폐지돼 아무 효과가 없다.**
효과 없는 값을 남겨 두면 다음 사람이 "이미 처리했다"고 믿는다.

**누를 것 같으면 미리 연결한다.** 썸네일에 마우스가 닿거나 초점이 오면
`youtube-nocookie.com` 에 연결을 열어 둔다. 누른 뒤에 손을 대면 그만큼 늦다.

## 하지 않은 것

**`<figure>` 로 감싸지 않았다.** `.prose figure img` 가 썸네일에 테두리와 모서리를 다시 얹고,
`.prose figcaption` 이 제목 띠를 가운데 정렬된 회색 글씨로 바꾼다.
둘 다 본문 그림을 위해 만든 규칙이라 여기서는 방해만 된다.

**썸네일을 R2 로 옮기지 않았다.** 그러면 동기화가 유튜브 주소를 따라다니며 그림을 굽는 일까지
해야 한다. 영상 하나 붙이자고 동기화에 새 실패 지점을 만들 이유가 없다(ADR-0051).
